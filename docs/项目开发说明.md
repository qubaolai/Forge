## 三、核心数据模型

### `adaptive/models.py`

```python
class RunStatus(str, Enum):
    CREATED     = "created"
    PLANNING    = "planning"
    VALIDATING  = "validating"
    EXECUTING   = "executing"
    INTEGRATING = "integrating"
    VERIFYING   = "verifying"
    COMPLETED   = "completed"
    FAILED      = "failed"
    BLOCKED     = "blocked"   # 需要人决策：冲突无法自动解决 / 超 replan 限制
    ABORTED     = "aborted"

class TaskStatus(str, Enum):
    PENDING   = "pending"
    RUNNING   = "running"
    COMPLETED = "completed"
    FAILED    = "failed"
    SKIPPED   = "skipped"   # dep 失败，级联跳过

class TaskKind(str, Enum):
    READ      = "read"       # 纯探索，无写操作
    WRITE     = "write"      # 产出代码 / 内容变更 → PatchSet
    EXECUTE   = "execute"    # 运行命令（测试、lint）
    REVIEW    = "review"     # 读取并判断
    INTEGRATE = "integrate"  # 合并多个产出

@dataclass(frozen=True)
class TaskNode:
    id: str
    title: str
    kind: TaskKind

    # Planner 声明，Validator 强制校验
    allowed_tools: tuple[str, ...]
    read_scope:    tuple[str, ...]   # 允许读取的路径前缀
    write_scope:   tuple[str, ...]   # 允许写入的路径前缀（READ 类必须为空）

    deps: tuple[str, ...] = ()
    model_profile: Literal["fast", "smart", "strong"] = "smart"
    max_steps: int = 25
    acceptance_criteria: str = ""
    output_contract: Literal[
        "patch_set", "discovery_report", "review_report",
        "test_report", "integration_report", "final_report"
    ] = "patch_set"

    # 运行时（可变）
    status:       TaskStatus      = TaskStatus.PENDING
    artifact_ids: tuple[str, ...] = ()
    error:        str | None      = None
    started_at:   datetime | None = None
    completed_at: datetime | None = None

@dataclass
class TaskGraph:
    nodes:       dict[str, TaskNode]   # task_id → TaskNode
    planner_raw: str      = ""         # Planner 原始输出，调试用
    created_at:  datetime = field(default_factory=_now)

@dataclass
class AdaptiveRun:
    run_id:         str
    workspace_path: str
    goal:           str
    status:         RunStatus = RunStatus.CREATED
    task_graph:     TaskGraph | None = None
    current_wave:   int  = 0
    replan_count:   int  = 0
    artifact_ids:   list[str] = field(default_factory=list)
    owner_user_id:  str  = "local"
    created_at:     datetime = field(default_factory=_now)
    updated_at:     datetime = field(default_factory=_now)
    metadata:       dict[str, Any] = field(default_factory=dict)
```

## 四、执行主流程

```
POST /api/v1/chat/completions
          ↓
    ModeRouter.route(message, mode, task_options)
    ┌─── chat ──────────────────────────────────────────────────────┐
    │  TurnOrchestrator.run_turn(...)   ← 现有路径不动              │
    └───────────────────────────────────────────────────────────────┘
    ┌─── adaptive_run ──────────────────────────────────────────────┐
    │  AdaptiveRunOrchestrator.run(goal, options)                   │
    │                                                                │
    │  Step 1: DISCOVER                                              │
    │    QuickDiscoveryExecutor（READ-only ReActAgent, ≤10 steps）   │
    │    → DiscoveryReport artifact                                  │
    │                                                                │
    │  Step 2: PLAN                                                  │
    │    Planner(goal + discovery_report + tool_allowlist)           │
    │    → TaskGraph JSON（严格结构，用 tool_use 强制输出）           │
    │                                                                │
    │  Step 3: VALIDATE                                              │
    │    TaskGraphValidator.validate(task_graph, options)            │
    │    规则：DAG无环 / deps存在 / tools在allowlist /               │
    │          write_scope在root_path下 / 同wave写冲突 /             │
    │          kind-tools一致性 / max_steps≤hard_cap                 │
    │    失败 → replan_count++ → 回 Step 2（超限 → BLOCKED）         │
    │                                                                │
    │  Step 4: EXECUTE（按 wave 循环）                               │
    │    Scheduler.compute_waves(task_graph)                         │
    │    → 每个 wave: asyncio.gather(TaskExecutor.run(node) for ...) │
    │                                                                │
    │    TaskExecutor.run(node):                                     │
    │      IsolateStrategy.prepare(node)  → 隔离环境                │
    │        ↓ GitWorktreeStrategy: git worktree add /tmp/forge-xxx  │
    │      TurnOrchestrator.run_turn(overrides={                     │
    │          tools=node.allowed_tools,                             │
    │          write_scope=node.write_scope,                         │
    │          system_prompt=_build_task_prompt(node, artifacts),    │
    │          max_steps=node.max_steps,                             │
    │          model_id=model_profiles[node.model_profile],          │
    │      })                                                        │
    │      → PatchSet artifact（含 changed_files / diff / base_ref） │
    │      IsolateStrategy.cleanup(node)                             │
    │                                                                │
    │  Step 5: INTEGRATE                                             │
    │    Integrator.merge(patch_sets, workspace_path)                │
    │    非冲突 → 直接合入                                           │
    │    文本冲突 → ConflictReport artifact                          │
    │    语义冲突 → BLOCKED（用户决策）                               │
    │    → IntegrationReport artifact                                │
    │                                                                │
    │  Step 6: VERIFY                                                │
    │    Verifier.run(options.verifier_cmd, workspace_path)          │
    │    pass → 继续                                                  │
    │    fail → 生成修复 TaskNode → replan_count++ → 回 Step 4      │
    │           超限 → BLOCKED                                       │
    │    → TestReport artifact                                       │
    │                                                                │
    │  Step 7: CLOSE                                                 │
    │    FinalReport artifact（TaskGraph + 所有 artifact 索引）       │
    │    RunStatus.COMPLETED                                          │
    └───────────────────────────────────────────────────────────────┘
```

## 八、workspace 写隔离（`adaptive/workspace.py`）

```python
class IsolateStrategy(Protocol):
    async def prepare(self, node: TaskNode, run: AdaptiveRun) -> IsolatedEnv: ...
    async def collect(self, env: IsolatedEnv) -> PatchSetPayload: ...
    async def cleanup(self, env: IsolatedEnv) -> None: ...

@dataclass
class IsolatedEnv:
    strategy: str           # "worktree" | "sandbox_copy"（未来）
    work_path: str          # agent 实际工作的目录
    base_ref:  str          # git worktree 的基 commit hash

class GitWorktreeStrategy:
    """当前唯一实现。要求 workspace 是 git repo。"""

    async def prepare(self, node, run) -> IsolatedEnv:
        work_path = f"/tmp/forge-{run.run_id[:8]}-{node.id}"
        await _run("git", "worktree", "add", work_path, "HEAD",
                   cwd=run.workspace_path)
        base_ref = await _git_head(run.workspace_path)
        return IsolatedEnv(strategy="worktree", work_path=work_path, base_ref=base_ref)

    async def collect(self, env) -> PatchSetPayload:
        diff = await _run("git", "diff", env.base_ref, cwd=env.work_path)
        changed = await _changed_files(env.work_path, env.base_ref)
        return PatchSetPayload(diff=diff, changed_files=changed, base_ref=env.base_ref)

    async def cleanup(self, env) -> None:
        await _run("git", "worktree", "remove", "--force", env.work_path)
```

## 十二、设计红线（不可逾越）

1. **Planner 只能声明资源，不能执行**：TaskGraph 里的 `allowed_tools` 必须过 Validator，超出 allowlist 的直接 reject，不是 warning。
2. **write_scope 路径必须在 workspace root_path 下**：Validator + executor 双重校验，越界 task 不进 wave。Executor 在 ToolExecutor 层进一步把 write_file/edit_file/git_ops 限制到 TaskNode 的 `write_scope`，read_scope 同理（C9/fix-4）。
3. **READ kind task 不能有写工具**：`kind="read"` + `write_scope` 非空 = Validator 拒绝；`allowed_tools` 含 write/shell/run_tests 一并拒绝。
4. **write task 必须走写隔离**：`writer_mode=isolated_worktree` 时，executor 不允许直接写主 workspace，只能写 worktree。
5. **adaptive 与 chat 共享 ReActAgent，但执行入口分叉**（D2 设计修订，原"TurnOrchestrator 接口不变 + RunTurnOverrides"已替换）：
    - chat 路径走 `forge/chat/orchestrator.py::TurnOrchestrator`，保留 session/message 持久化、guards/runner、resume 等聊天专属语义。
    - adaptive 路径走 `forge/adaptive/task_runner.py::run_node_with_react`，独立包装 ReActAgent，**不复用 TurnOrchestrator**。理由：一次性任务执行不需要 session 持久化（artifact 已替代）、不需要 loop guard、不需要 message resume。
    - 共享的部分：`ReActAgent` + `LLM client / chain` + `ToolRegistry`。任何对这些原语的修改必须同时兼顾两条路径。
6. **聊天路径零退化**：`mode=chat` 或 `mode=auto` 且路由为 chat 时，走原 TurnOrchestrator 路径，adaptive 层完全不参与。
7. **fallback 路径不可遮蔽真实执行失败**（C10/D1 新增）：
    - `task_execution.enable_real_llm` 默认 **true**。LLM/Discovery/Planner 任一步失败 → run FAILED，绝不退化到占位 PatchSet 假完成。
    - 测试环境通过 `sys_config.test.yaml` 显式置 false，且单测使用 fallback 时必须显式构造 `TaskExecutor(enable_real_llm=False)`。
    - WRITE 任务空 PatchSet（`changed_files=[]` 且 `agent_output=None`）在 `enable_real_llm=true` 路径下视为未真正执行 → 任务 FAILED。
    - FinalReport.payload 与 `run.metadata` 均暴露 `execution_mode: "real" | "fallback"`，客户端可据此判断本次 run 是否可落地。
8. **状态机硬约束**（C6/D4 新增）：
    - `orchestrator._set_status` 与 `executor._set_run_status` 走 `store.transition_status` 校验合法转换；非法转换直接 raise，不再降级直写。
    - 单测必须显式 `await store.save_run(...)` + 按合法链推到目标前置状态。
9. **HITL 决策必须经 supervisor**（B5 配套）：
    - BLOCKED 状态只能通过 `POST /runs/{id}/decide` 解除：`continue` 触发 `supervisor.resume_run`，`abort` 触发 `cancel_run`。
    - `decide continue` 复用历史 task_graph 与 `metadata.discovery_summary`，不重做 DISCOVER。
10. **多租户隔离**（N1 新增）：
    - 所有 `/api/v1/runs` 与 `/api/v1/artifacts` endpoint 在返回前必须经过 `_ensure_owner(run, user)`；admin/owner 角色可见全部。
    - 全局 `~/.assistant/adaptive_runs_index.jsonl`（C11/D6）为查询型 API 反查 workspace_path，但不绕过 owner 校验。
