# 统一上下文管理系统（Context Management System）

## Context

当前上下文管理逻辑散落在 5 个不同模块中，存在以下核心问题：

1. **历史消息不区分相关性**：取最近 N 条消息一律注入，与当前话题无关的历史轮次分散 LLM 注意力
2. **工具调用结果直接塞入上下文**：file read 等大结果跨轮持久化后再被 load_recent 拉回，导致上下文窗口爆掉
3. **压缩与上下文构建耦合**：`ContextAssembler` 同时承担 prompt 渲染、builder 调用、压缩决策三职，无法独立触发
4. **内容收集是顺序的**：`CompositeContextBuilder` 虽然内部用 `asyncio.gather`，但整体仍被 assembler 顺序调用，Prompt 渲染和内容收集没有并行
5. **adaptive / workflow 路径孤立**：无法复用上下文构建能力

> 注意：本文是历史方案文档。当前实现已将文中的 `Protocol` 扩展点收敛为需要显式继承的 `ABC`。

目标：抽取独立顶层模块 `context_mgmt/`，对外统一入口 `ContextManager`，内部以 Fork-Join 并行构建，压缩子系统完全解耦可独立触发，三种模式（chat / task / workflow）通过抽象扩展点切换行为。

## 三个核心架构决策

### 决策 A：WindowBudget 只管输入分区，不包含 output

`output_budget` 不是上下文窗口分配的一部分，它是 LLM 调用时的 `max_tokens`。
`WindowBudget` 管三个输入分区，剩余空间由计算属性推出：

```python
@dataclass(frozen=True)
class WindowBudget:
    context_window: int
    system_budget: int        # system prompt + facts + summary
    dialogue_budget: int      # 纯对话轮次（user/assistant 文本）
    tool_result_budget: int   # 工具结果（经 ToolResultPolicy 处理后）

    @property
    def total_input_budget(self) -> int:
        return self.system_budget + self.dialogue_budget + self.tool_result_budget

    @property
    def max_output_tokens(self) -> int:
        """建议传给 LLM 的 max_tokens 参数。"""
        return self.context_window - self.total_input_budget

    def validate(self) -> None:
        assert self.total_input_budget < self.context_window
```

### 决策 B：Fork-Join 并行构建，不用顺序 Pipeline

内容收集的各 Provider 彼此无依赖，Prompt 渲染与内容收集也无依赖，两者并行，
只有 MessageAssembler 需要等待两路结果汇合：

```
ContextRequest
      │
      ├─────────────────────────[fork]──────────────────────────┐
      │                                                          │
      ▼                                                          ▼
PromptRenderer.render(request)               ContentGatherer.gather(request)
  - 渲染 Jinja2 模板 或                         asyncio.gather(
    直接使用 system_prompt_override                 HistoryProvider,   ← 内含 Filter + ToolResultPolicy
                                                    SummaryProvider,
                                                    FactsProvider,
                                                    WorkspaceProvider,
                                                    [WorkflowStepProvider]
                                                )
      │                                                          │
      └──────────────────────[join]──────────────────────────────┘
                                  │
                                  ▼
                         MessageAssembler.assemble(
                             rendered_prompt,
                             chunks,          ← 各 Provider 的 ContentChunk
                             budget,          ← WindowBudget
                         )
                                  │
                                  ▼
                           ContextSnapshot
```

### 决策 C：压缩子系统完全解耦，支持独立触发

`CompactionController` 是独立子系统，`ContextManager` 只是其调用方之一。
CLI / API 可以绕过 `ContextManager` 直接调用 `compact_now()`：

```
ContextManager ──build()──► ContextBuilder（Fork-Join）
                                  │
                    （构建后检查）  │
                                  ▼
CompactionController ◄── threshold_trigger.should_compact(snapshot)
      │
      ├── compact_if_needed(session_id, snapshot)  ← ContextManager 自动调用
      └── compact_now(session_id)                  ← CLI / API 显式触发
            │
            ▼
      CompactionStrategy.compact()
      ├── SummaryCompaction（当前实现）
      ├── SelectiveDropCompaction（按相关性剔除旧轮次）
      └── HybridCompaction（先 drop 再 summary）
```

class TokenMeter(Protocol):

class BudgetPolicy(Protocol):
    def allocate(self, request: ContextRequest) -> WindowBudget: ...

@runtime_checkable
class ContentProvider(Protocol):
    async def provide(self, request: ContextRequest) -> list[ContentChunk]: ...
    @property
    def name(self) -> str: ...

class HistoryFilter(Protocol):
    async def filter(
        self,
        messages: list[HistoryMessage],
        query: str,

class ToolResultPolicy(Protocol):
    def process(
        self,
        tool_name: str,
        original_content: str,
        token_budget: int,
        meter: TokenMeter,

class CompactionStrategy(Protocol):
    """执行一次压缩，与触发逻辑无关。"""

        self,
        session_id: str,

## DefaultContextBuilder（Fork-Join 并行）

```python
class DefaultContextBuilder:
    """无状态，线程/协程安全。同一实例可并发处理多个请求。"""

    def __init__(
        self,
        renderer: PromptRenderer,
        gatherer: ContentGatherer,
        assembler: MessageAssembler,
        budget_policy: BudgetPolicy,
    ) -> None: ...

    async def build(self, request: ContextRequest) -> ContextSnapshot:
        budget = self._budget_policy.allocate(request)

        # Fork：渲染和内容收集完全并行
        rendered_prompt, chunks = await asyncio.gather(
            self._renderer.render(request),
            self._gatherer.gather(request),
        )

        # Join：组装（串行，依赖上面两路结果）
        return self._assembler.assemble(request, rendered_prompt, chunks, budget)
```

```python
class ContentGatherer:
    """并行调用所有 ContentProvider，独立处理每个 Provider 的失败。"""

    def __init__(self, providers: list[ContentProvider]) -> None: ...

    async def gather(self, request: ContextRequest) -> dict[str, list[ContentChunk]]:
        results = await asyncio.gather(
            *[p.provide(request) for p in self._providers],
            return_exceptions=True,
        )
        chunks: dict[str, list[ContentChunk]] = {}
        for provider, result in zip(self._providers, results):
            if isinstance(result, Exception):
                logger.warning("Provider %s 失败: %s", provider.name, result)
                # 失败记录到调用方的 snapshot.degraded，gather 本身不持有状态
            else:
                chunks[provider.name] = result
        return chunks
```

## CompactionController（独立子系统）

```python
class CompactionController:
    """压缩控制器，与 ContextBuilder 完全解耦。

    可由三种方式触发：
    1. ContextManager 在每次 build 后自动检查（ThresholdTrigger）
    2. CLI 命令显式触发（compact_now）
    3. API 端点触发（compact_now）
    """

    def __init__(
        self,
        strategy: CompactionStrategy,
        trigger: CompactionTrigger,
    ) -> None: ...

    async def compact_if_needed(
        self,
        session_id: str,
        snapshot: ContextSnapshot,
    ) -> CompactionResult | None:
        """由 ContextManager 在 build 后调用。不满足触发条件时返回 None。"""
        if not self._trigger.should_compact(snapshot):
            return None
        return await self._strategy.compact(session_id, snapshot)

    async def compact_now(self, session_id: str) -> CompactionResult:
        """CLI / API 显式触发，绕过触发条件判断直接执行。"""
        dummy_snapshot = ContextSnapshot(messages=[], budget=...) 
        return await self._strategy.compact(session_id, dummy_snapshot)
```

```python
# CompactionTrigger 实现

class ThresholdTrigger:
    """token 使用率超过阈值时触发。"""
    def __init__(self, threshold: float = 0.85) -> None: ...
    def should_compact(self, snapshot: ContextSnapshot) -> bool:
        return (
            snapshot.history_messages_dropped > 0
            or snapshot.usage_ratio > self._threshold
        )

class ExplicitTrigger:
    """始终返回 True，用于 compact_now 场景（无需额外判断）。"""
    def should_compact(self, snapshot: ContextSnapshot) -> bool:
        return True

class CompositeTrigger:
    """OR 逻辑：任一子触发器满足则触发。"""
    def __init__(self, triggers: list[CompactionTrigger]) -> None: ...
    def should_compact(self, snapshot: ContextSnapshot) -> bool:
        return any(t.should_compact(snapshot) for t in self._triggers)
```

## ContextManager（组合入口）

```python
class ContextManager:
    """无状态，组合 ContextBuilder 和 CompactionController。"""

    def __init__(
        self,
        builder: DefaultContextBuilder,
        compaction: CompactionController,
    ) -> None: ...

    async def build(self, request: ContextRequest) -> ContextSnapshot:
        """构建上下文，按需触发压缩并重建。"""
        snapshot = await self._builder.build(request)

        result = await self._compaction.compact_if_needed(request.session_id, snapshot)
        if result and result.success:
            # 压缩后重建（snapshot 更新了 session 的 summary）
            snapshot = await self._builder.build(request)
            snapshot.degraded.append("active_compaction_triggered")

        return snapshot

    async def compact_now(self, session_id: str) -> CompactionResult:
        """CLI / API 显式压缩入口。"""
        return await self._compaction.compact_now(session_id)
```

## 压缩入库的触发源处理原则

`SummaryStore` **不存储触发源**，理由：
- 存储层只关心"到 message_id=X 为止的摘要内容"，触发源与内容无关
- 阈值触发和 CLI 触发生成的 summary 结构完全相同，存储 schema 不变
- 触发源属于可观测层，写入 log / SSE 事件 / `CompactionResult.trigger_source`，不下沉到存储

```python
@dataclass
class CompactionResult:
    success: bool
    tokens_saved: int = 0
    strategy_used: str = ""
    trigger_source: str = ""    # "threshold" | "explicit" | "scheduled" —— 仅用于 log/SSE
    failure_reason: str = ""
```

`CompactionController.compact_now()` 产出的 `CompactionResult.trigger_source = "explicit"`，
`compact_if_needed()` 产出的为 `"threshold"`，调用方决定是否发 SSE 事件或记录 span，存储层无感。

### ContextUsage（结构化用量视图）

```python
@dataclass(frozen=True)
class LayerUsage:
    """单个上下文层的用量。"""
    name: str              # 层名称（见下方标准层列表）
    token_count: int
    ratio: float           # token_count / context_window
    message_count: int = 0 # 消息条数（对 history / tool_results 有意义）
    truncated: bool = False # 本层是否被裁剪过


@dataclass
class ContextUsage:
    """可直接渲染到 CLI / 前端的上下文用量快照。"""
    context_window: int
    total_input_tokens: int
    max_output_tokens: int      # = context_window - total_input_tokens（建议 max_tokens 值）
    total_ratio: float          # total_input_tokens / context_window

    # 有序层列表（渲染顺序 = 在 system message 中的组合顺序）
    layers: list[LayerUsage]

    # 快速健康信号
    @property
    def is_warning(self) -> bool:   # ratio > 0.70
    @property
    def is_critical(self) -> bool:  # ratio > 0.90
    @property
    def needs_compaction(self) -> bool:  # 有历史被截断 OR ratio > 0.85

    def render_ascii(self) -> str:
        """CLI 用：生成类似 Claude Code 的用量条形图。"""
        # ████░░░░░░  68% (87,040 / 128,000 tokens)
        # ├ system_prompt   12% ██
        # ├ workspace        3% ░
        # ├ facts            2% ░
        # ├ summary          5% █
        # ├ dialogue        35% ██████
        # ├ tool_results    11% ██
        # └ current_input    0% ░
```

**标准层名称**（`LayerUsage.name`）：

| 层名 | 内容 | 对应 Provider |
|------|------|--------------|
| `system_prompt` | 基础系统提示词 | `PromptRenderer` |
| `workspace` | ASSISTANT.md + workspace settings | `WorkspaceProvider` |
| `facts` | 长期用户事实 | `FactsProvider` |
| `summary` | 早期对话摘要（压缩后注入） | `SummaryProvider` |
| `dialogue` | 对话历史（user/assistant 文本轮次） | `HistoryProvider` |
| `tool_results` | 工具调用结果历史 | `HistoryProvider`（分离统计） |
| `workflow_step` | 工作流步骤输入 + 跨步 artifacts | `WorkflowStepProvider` |
| `current_input` | 本轮用户消息 | `MessageAssembler` 直接产出 |

### MessageAssembler 产出 ContextUsage

`MessageAssembler.assemble()` 在组装完 messages 后，按 `chunk.layer` 聚合产出 `ContextUsage`：

```python
def assemble(
    self,
    request: ContextRequest,
    rendered_prompt: str,
    chunks: dict[str, list[ContentChunk]],
    budget: WindowBudget,
) -> ContextSnapshot:
    # ... 组装 messages ...

    # 聚合各层 token 数
    layers = self._aggregate_layers(rendered_prompt, chunks, all_messages)
    usage = ContextUsage(
        context_window=budget.context_window,
        total_input_tokens=total_tokens,
        max_output_tokens=budget.max_output_tokens,
        total_ratio=total_tokens / budget.context_window,
        layers=layers,
    )
    return ContextSnapshot(..., usage=usage)
```

### ContextManager 缓存 + 查询接口

```python
class ContextManager:
    def __init__(self, builder, compaction) -> None:
        self._builder = builder
        self._compaction = compaction
        # 按 session_id 缓存最近一次 usage（内存，进程级）
        self._usage_cache: dict[str, ContextUsage] = {}

    async def build(self, request: ContextRequest) -> ContextSnapshot:
        snapshot = await self._builder.build(request)
        # 构建完成后立即写入缓存
        self._usage_cache[request.session_id] = snapshot.usage

        result = await self._compaction.compact_if_needed(
            request.session_id, snapshot
        )
        if result and result.success:
            snapshot = await self._builder.build(request)
            self._usage_cache[request.session_id] = snapshot.usage
            snapshot.degraded.append("active_compaction_triggered")

        return snapshot

    def get_current_usage(self, session_id: str) -> ContextUsage | None:
        """近实时查询：返回该 session 最近一次构建的用量快照。
        
        无 IO，纯内存读取，延迟 < 1ms。
        CLI 和前端可按需 poll（建议间隔 1-2s）或在 SSE 事件后拉取。
        """
        return self._usage_cache.get(session_id)

    async def compact_now(self, session_id: str) -> CompactionResult:
        """CLI 显式压缩入口。"""
        return await self._compaction.compact_now(session_id)
```

## BudgetPolicy 按 mode 给比例

```python
class DefaultBudgetPolicy:
    _RATIOS = {
        ContextMode.CHAT: {
            "system": 0.15, "dialogue": 0.40, "tool_result": 0.15
            # max_output_tokens = context_window × 0.30（计算属性）
        },
        ContextMode.TASK: {
            "system": 0.20, "dialogue": 0.00, "tool_result": 0.50
            # max_output_tokens = context_window × 0.30
        },
        ContextMode.WORKFLOW: {
            "system": 0.20, "dialogue": 0.15, "tool_result": 0.35
            # max_output_tokens = context_window × 0.30
        },
    }

    def allocate(self, request: ContextRequest) -> WindowBudget:
        ratios = self._RATIOS[request.mode]
        w = request.context_window
        return WindowBudget(
            context_window=w,
            system_budget=int(w * ratios["system"]),
            dialogue_budget=int(w * ratios["dialogue"]),
            tool_result_budget=int(w * ratios["tool_result"]),
        )
```
